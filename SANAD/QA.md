# نتائج التحقق — المرحلة الأولى

## فحوص ناجحة

- اجتاز JavaScript فحص البنية عبر `node --check`.
- فُحص HTML: معرّفات فريدة، عنوان رئيسي واحد، جميع الروابط الداخلية تصل إلى أهداف موجودة، وجميع موارد CSS وJavaScript موجودة بمسارات نسبية.
- خمس بطاقات تخصصات غير تفاعلية وثلاث بطاقات أدوات تعريفية دون أزرار تشغيل.
- لا نماذج أو إدخال بيانات أو iframe أو API أو تخزين محلي أو ملفات تعريف ارتباط أو روابط موارد خارجية في المصدر.
- أيقونات SVG زخرفية مستبعدة من قارئ الشاشة، واتجاه الصفحة عربي RTL.
- توجد قواعد تقليل الحركة، ونقاط تحول 600px و900px، وتلتف الأزرار وعناصر رؤوس البطاقات. لا إخفاء للتمرير الأفقي لإخفاء أخطاء العرض.
- اختُبر منطق قائمة الهاتف بمحاكاة DOM: الحالة الأولية مغلقة، الفتح بالنقر، تحديث aria-expanded، الإغلاق بـ Escape وإعادة التركيز، إغلاق القائمة ونقل التركيز لهدف الرابط، الإغلاق عند النقر أو انتقال التركيز خارج الشريط، والتحول بين عرض الهاتف والكمبيوتر.

## حدود التحقق

لم يُنجز فحص بصري فعلي عند 360px أو على الكمبيوتر، ولا اختبار Enter وSpace وTab داخل متصفح حقيقي. حاولنا تشغيل Chromium، لكنه غير مثبت، وتعذّر تنزيله في بيئة التنفيذ. محاكاة DOM تفحص منطق الشيفرة فقط ولا تثبت سلوك المتصفح أو قارئ الشاشة أو خلو العرض من التمرير الأفقي.

القائمة تستخدم زر HTML أصليًا لدعم Enter وSpace، وروابط أصلية تدعم Tab؛ يلزم تأكيد ذلك فعليًا. لم يُجرَ اختبار على Safari أو Firefox أو هاتف حقيقي. اختلاف الخطوط المحلية قد يغير توزيع السطور.

## قائمة مراجعة المتصفح عند توفره

1. افتح `dist/index.html` بعرض 360px ثم 1440px، وتحقق أن `document.documentElement.scrollWidth <= window.innerWidth`، وافحص جميع الأقسام بصريًا.
2. استخدم Tab للوصول إلى رابط التخطي ثم زر القائمة؛ افتح بـ Enter وبـ Space، وأغلق بـ Escape. تأكد من رجوع التركيز للزر ووضوح حد التركيز.
3. جرّب الروابط الأربعة في القائمة وزري الترحيب. يجب أن تظهر الأقسام المقصودة، وتغلق قائمة الهاتف ويصل التركيز إلى هدف الرابط.
4. افتح القائمة ثم غيّر العرض إلى الكمبيوتر وارجع للهاتف؛ يجب ألا يبقى التركيز داخل قائمة مخفية.
5. اختبر تكبير النص إلى 200% وتقليل الحركة وتعطيل JavaScript؛ عند تعطيله يجب أن تبقى روابط التنقل ظاهرة.
6. انشر محتويات `dist` داخل مجلد فرعي وتحقق من تحميل CSS وJavaScript بنجاح.

لم تُنفّذ الأدوات أو الحسابات. توقّف العمل عند المرحلة الأولى.
