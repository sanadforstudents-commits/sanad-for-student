# سند الطالب | SANAD — وثيقة المشروع المحدثة (المرحلة الرابعة)

مبادرة طلابية مستقلة لخدمة طلاب كلية الذكاء الاصطناعي في جامعة البلقاء التطبيقية.

---

## المنجز في المرحلة الرابعة: إطلاق أداة «خطة الدراسة»

تم بناء أداة تخطيط المذاكرة والامتحانات بنظام حتمي محلي كامل يعتمد على القواعد الأكاديمية الصارمة دون ذكاء اصطناعي:

1. **المدخلات والتكامل الشامل**:
   - ربط مباشر بمواد الطالب وموضوعاتها السابقة مع إمكانية إضافة موضوع جديد عند الحاجة.
   - تحديد موعد الامتحان (تاريخ ووقت)، والوقت التقديري المتبقي، والصعوبة، والأولوية، ومستوى الفهم.
   - الفصل بين نوع العمل: دراسة نظرية أو تطبيق عملي.
   - تحديد وحجز وقت مراجعة إلزامي يسبق الامتحان مباشرة.

2. **التكامل مع الجدول المحفوظ**:
   - استبعاد أوقات المحاضرات المسجلة في الجدول المحفوظ تلقائياً وإضافة وقت انتقال وراحة بعد المحاضرات الوجاهية.
   - عدم المساس بجدول المحاضرات أو تعديله من أداة الخطة.
   - تنبيه صريح في حال تعديل المحاضرات بعد توليد الخطة.

3. **خوارزمية التوزيع والحفاظ على الشفافية**:
   - إعطاء الأولوية القصوى للمواعيد الأقرب (Deadlines) ثم الأولوية والصعوبة ومستوى الفهم.
   - تقسيم الموضوعات الطويلة إلى جلسات منتظمة (مثلاً 50 دقيقة) وفترات استراحة (10 دقائق) محسوبة ضمن الوقت المشغول.
   - عدم وضع أي جلسة بعد موعد الامتحان إطلاقاً.
   - حساب دقيق للعجز الزمني عند عدم كفاية الفترات وإظهار الموضوعات المتأثرة والدقائق المتبقية دون تمويه.
   - إظهار التنويه المعتمد: «الناتج توزيع مقترح وفق القواعد، وليس ضماناً لأفضل توزيع ممكن».

4. **الواجهة وإعادة التوزيع الآمنة**:
   - عرض خطة اليوم وخطة الأسبوع الكاملة.
   - إجراءات الجلسة: إنجاز كامل، إنجاز جزئي مع حساب الدقائق المتبقية بدقة، وتأجيل.
   - تعديل التوقيت اليدوي مع فحص عدم التعارض مع المحاضرات أو المواعيد النهائية.
   - إعادة التوزيع: معاينة مسبقة للتغييرات والعجز، طلب تأكيد الطالب قبل التطبيق، والحفاظ على المهام المنجزة مسبقاً.
   - معالجة التواريخ بدوال محلية (Local Date) لمنع أي انزياح بسبب فرق التوقيت UTC.

## فحوصات التحقق وضمان الجودة المنجزة (QA Checklist)

- [x] **وقت كافٍ**: جدولة كافة الجلسات قبل مواعيد الامتحانات وعجز = 0.
- [x] **وقت غير كافٍ وعجز ظاهر**: بيان عدد الدقائق والعجز والموضوعات المتأثرة بدقة عند ضيق الوقت.
- [x] **يوم بلا وقت متاح**: احترام أيام الإجازة وتخطي الأيام ذات الساعات الصفرية.
- [x] **امتحان اليوم أو موعد مضى**: حظر الجدولة بعد الموعد النهائي وجدولة المراجعة في الساعات السابقة للامتحان فقط.
- [x] **تجزئة الموضوع الطويل**: تقسيم 120 دقيقة إلى جلسات 50 + 50 + 20 مع فواصل الاستراحة.
- [x] **إنجاز جزئي وإعادة توزيع**: خصم الدقائق المنجزة والاحتفاظ بها وإعادة جدولة الباقي فقط بعد التأكيد.
- [x] **حظر التعارض مع المحاضرات**: استبعاد مواعيد المحاضرات الجامعية المحفوظة من نوافذ المذاكرة.
- [x] **سلامة التواريخ محلياً**: اختبار التواريخ في منطقة GMT+3 والتأكد من عدم انتقال اليوم.
